# 🏆 Online Exam Leaderboard Tracker

A professional, full-stack web application designed for tracking student performance across multiple quiz subjects. Built with **Flask**, **SQLAlchemy**, and a premium **Glassmorphism** UI.

## 🚀 Live Demo
Check out the live application here:  
**[https://online-exam-leaderboard-tracker-original.onrender.com/](https://online-exam-leaderboard-tracker-original.onrender.com/)**

---

## ✨ Features
- **Multiple Subjects**: Choose between Python, C++, and JavaScript.
- **Dynamic Grading**: Instant automated scoring upon submission.
- **Real-time Leaderboard**: See where you rank against others immediately.
- **SQL Integration**: Persistent storage using an SQL database.
- **Premium UI**: Modern dark theme with smooth animations and glassmorphism effects.

## 🛠️ Technology Stack
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Backend**: Python, Flask
- **Database**: SQL (SQLite / MySQL supported)
- **Deployment**: Render

## 📝 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Bosco37/Online-exam-leaderboard-tracker-original.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   python app.py
   ```
4. Open your browser at `http://127.0.0.1:5000`
